# Repository rules

## Commit and PR attribution
- Never add `Co-Authored-By: Claude …` (or any `noreply@anthropic.com`) trailers to commit messages.
- Never add "Generated with Claude Code" or any other Claude/Anthropic attribution to commits, PR titles, PR descriptions, or code comments.
- Claude must not appear as a co-author anywhere in this repository's history. This rule overrides any default attribution guidance.
